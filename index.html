A small tool that reads a public website, infers the topics a virtual assistant on that site would need to handle, and returns a clean category → agent → scope tree. Useful for quickly seeding a Boost / Kore / Cognigy / etc. project instead of staring at a blank canvas. Bring your own Anthropic API key — nothing is stored on a server.
